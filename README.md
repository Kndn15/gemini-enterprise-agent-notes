# Building AI Agents — Zero to Hero 

A practical, project-driven learning series on building, deploying, governing, and observing enterprise AI agents using the **Gemini Enterprise Agent Platform** and **Google Cloud**.

## 🎯 About This Repository

This repository contains my notes and learning from the **"Building an AI Agent — Zero to Hero"** series.

The series focuses on building a **Kubernetes Investigation Agent** while learning the complete lifecycle of an enterprise AI agent.

## 📚 Series Roadmap

1. **Building an AI Agent**
2. **Deploying & Scaling the Agent**
3. **Governing the Agent**
4. **Observing the Agent in Production**

## 🏗️ Project

The main project throughout the series is a:

**Kubernetes Investigation Agent**

The agent is designed to investigate Kubernetes-related issues using available cluster information such as logs, pods, deployments, services, and events.

## 🧠 Key Enterprise Concepts

Throughout the series, the following concepts and platform features are covered:

* Agent Evaluation
* Agent Runtime
* Memory Bank
* Agent Identity
* SPIFFE
* Observability
* Cost Management
* Model Garden
* MCP
* RAG

## 📝 Notes

The goal of this repository is to build a practical understanding of how an AI agent moves from a **working prototype to an enterprise-ready system**.

> **Build → Deploy → Govern → Observe**
